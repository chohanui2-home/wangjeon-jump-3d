# 왕전초점프왕 3D

**3인칭 로블록스 오비 스타일 3D 점프맵** 게임입니다.
`왕전초 연산왕` · `왕전초 타이머왕` · `왕전초 눈치왕` · `왕전초 점프왕`과 같은 왕전초 시리즈이고,
바로 앞 버전 `점프왕`(2D 가로 스크롤)을 3D로 새로 만든 게임이에요.

**바로 플레이:** https://chohanui2-home.github.io/wangjeon-jump-3d/

## 게임 규칙

- 캐릭터 등 뒤 위쪽에서 코스를 내려다보는 **3인칭 3D 시점**이에요. 화면을 좌우로 살짝 밀면 시야가 돌아가고, 손을 떼면 정면으로 돌아와요.
- 왼쪽 **▲ ◀ ▶ ▼** 패드로 앞·뒤·옆으로 달리고, 오른쪽 **점프 ⬆** 버튼으로 뛰어요. 손가락으로 대각선으로 밀면 8방향 이동도 돼요. 키보드는 방향키·WASD + 스페이스.
- **점프를 한 번 더 누르면 🌀 회오리 점프!** 공중에서 캐릭터가 360° 빙글빙글 돌고, 입체 소용돌이 바람 링과 함께 더 높이·더 멀리 날아가요.
- 발판 아래에는 **붉게 빛나는 3D 바닥 레이저 격자 바다**가 있어요. 떨어지거나 발판 위 **빨간 레이저 기둥**에 닿으면 찌릿! 실수가 하나 올라가고 가장 최근에 밟은 **🚩 체크포인트**(없으면 단계 시작점)로 되돌아가요. 죽지는 않아요.
- **🌀 회오리벽**은 그냥 점프로는 막혀요(튕겨 나올 뿐 다치지 않음). **회오리 점프로 돌면서** 부딪히면 팡! 하고 바람 파편과 함께 부서지며 돌파!
- 캐릭터 바로 아래 발판에 **둥근 착지 그림자**가 떨어져서, 3D에서도 어디에 착지할지 한눈에 보여요.
- ⭐ 별을 모으고, 🏁 골인 아치에 닿으면 클리어!

## 🎥 3인칭 ↔ 👀 1인칭

제목 아래 `🎥 3인칭` 버튼을 누르면 **1인칭 시점**으로 바뀌어요. 버튼 한 번으로 언제든 오갈 수 있고, 고른 시점은 기억돼요.

- 1인칭에서는 카메라가 캐릭터 **눈높이**로 옮겨 가고 캐릭터 몸은 화면에서 사라져서, 발판·레이저·회오리벽이 눈앞에 펼쳐져요.
- 1인칭에서도 2단 회오리 점프는 그대로! 화면 둘레로 소용돌이 바람이 휘감겨요.
- 화면을 좌우로 밀면 1인칭에서 더 넓게 둘러볼 수 있어요.

## 6단계

| 단계 | 이름 | 내용 |
|---|---|---|
| 1 | 첫 걸음 | 넓은 3D 발판 + 레이저 기둥 + 첫 회오리벽 |
| 2 | 장애물 레이저 | 발판 한가운데 레이저 기둥을 옆으로 돌아서 통과 |
| 3 | 움직이는 발판 | 좌우·앞뒤로 오가는 발판에 올라타고 건너기 |
| 4 | 지그재그 회오리 | 좌우로 꺾이는 코스 + 연속 회오리벽 2개 |
| 5 | 고공 계단 | 레이저 바다 위로 계단처럼 솟는 좁은 발판 |
| 6 | 점프왕 코스 | 체크포인트 2개 · 움직이는 발판 · 레이저 기둥 · 회오리벽 총집합 |

화면 맨 아래 탭에서 언제든 단계를 바꿀 수 있고, 클리어한 단계에는 ★(별 1~2개) · ♛(별 3개) 표시가 붙어요.

## 특징

- **직접 만든 3D 엔진** — 외부 3D 라이브러리(Three.js 등) 없이, 원근 투영 + 화가 정렬 + 면 음영으로 3D를 그립니다. 그래서 모든 휴대폰 WebView·오프라인 파일·구형 브라우저에서 WebGL 오류 없이 똑같이 그려져요.
- **초등학생 손에 맞춘 조작** — 멀티터치 패드로 이동과 점프를 동시에, 2단 점프(회오리), 코요테 타임(발판 끝을 살짝 지나쳐도 점프), 점프 버퍼링(미리 눌러도 착지하자마자 점프).
- **6단계 모두 실제로 깨지는지 검증** — 게임과 똑같은 물리 엔진을 오토파일럿이 직접 달려서 1~6단계를 모두 완주하는지 자동 테스트로 확인합니다.
- **사람 캐릭터** — 둥근 얼굴·라벤더 티셔츠·파란 반바지·민트 운동화를 신은 아이가 달리기 팔다리 흔들림, 점프, 회오리 회전, 감전 표정을 지어요.
- **라벤더·민트·레몬 하늘 테마** — 떠 있는 3D 구름과 파스텔 하늘, 붉은 레이저 바다의 대비.
- **기록 저장** — 단계별 최고 기록(시간·실수·별)을 브라우저에 저장하고, 새 기록이면 '새 기록!' 표시.
- **효과음** — 점프·회오리·별·체크포인트·감전·회오리벽 파괴·클리어 팡파레 (Web Audio API, 음소거 가능).
- **외부 리소스 0건** — 폰트·CDN·이미지·오디오를 하나도 불러오지 않는 단일 HTML 파일. 파일 하나만 보내도 오프라인에서 그대로 열립니다.
- **앱처럼 설치** — 홈 화면에 추가하면 전체화면 앱처럼 열립니다(PWA 메타·아이콘·매니페스트 포함).

## 파일

- `index.html` — 게임 전체가 들어 있는 단일 파일(외부 요청 0건)
- `app_template.html` — 빌드용 템플릿(아이콘 자리표시자 포함)
- `build.py` — 아이콘 주입·단일 파일 규칙 검사 후 `index.html`과 `dashboards/왕전초-점프왕-3D.html`에 같은 바이트로 기록
- `test_app.py` — QuickJS로 게임 스크립트를 실행해 3D 물리·발판 충돌·레이저 바다/기둥 리스폰·체크포인트·움직이는 발판·회오리벽·3인칭↔1인칭 시점·1~6단계 도달 가능성을 검사하는 자동 테스트

## 다시 빌드하기

```bash
python3 build.py      # index.html + dashboards/왕전초-점프왕-3D.html 생성
python3 test_app.py   # 자동 테스트
```
